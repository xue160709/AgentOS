# Sub-agent 上下文共享规则

## 目标

让 sub-agent 获得足够完成任务的信息，同时避免完整对话、无关材料、原始日志和其他角色草稿造成上下文污染。

## 默认策略

主 Agent 默认不复制完整主线程，而是给 sub-agent 一个精简任务包，并提供需要读取的项目文件路径。稳定信息写入项目文档，避免每次重新说明或重新搜索。

## 继承层级

### 不继承历史

适用于边界清楚的研究、文档、设计、架构、实现、测试和审查任务。任务包必须完整包含目标、约束和相关路径。

### 继承最近若干轮

适用于用户刚补充了会改变结果的重要语义，但尚未写入项目文档的情况。只继承包含该语义的最少轮次。

### 继承全部历史

只适用于分析完整产品探索过程、决策演变或用户长期意图的任务。完成后应把稳定结论沉淀为文档，后续恢复按需共享。

## 任务包模板

```markdown
## 任务目标
需要得到什么结果。

## 背景与原因
为什么现在需要处理。

## 已确认事实
只写已被用户或主 Agent 确认的内容。

## 待验证假设
明确仍不确定的判断。

## 相关资料
列出需要读取的具体文件路径。

## 范围与所有权
允许读取、修改和创建的路径，以及不可改变项。

## 搜索权限
是否允许公开搜索、搜索目的、来源要求和禁止的外部操作。

## 交付要求
需要返回的结论、文档或代码，以及验证要求。

## 停止条件
出现什么冲突、风险或缺失信息时必须交回主 Agent。
```

## 必须共享

- 任务目标、业务原因和成功标准。
- 已确认的用户要求、产品事实和决策。
- 当前范围、非目标、不可改变项和文件所有权。
- 与任务直接相关的 PRD、研究、设计、架构、代码和验收文件路径。
- 允许的搜索范围、写入范围和外部操作边界。

## 按需共享

- 最近对话中的重要语义。
- 原始访谈、完整市场资料和竞品页面。
- 大型日志、截图、设计参考和完整测试记录。
- 其他 Agent 的结论；默认只共享摘要和证据路径。
- 已否决方案；只有防止重复或比较取舍时才提供。

## 默认不共享

- 无关历史对话。
- 其他 Agent 的思考草稿和未经确认的中间结论。
- 大量原始搜索结果、构建日志和测试输出。
- 与任务无关的个人信息、密钥、账号和敏感数据。

## 防止重复获取

- 外部研究需要落盘时写入主 Agent 在任务包中指定的精确 `docs/` 路径，并包含来源、日期、结论和适用范围；`docs/` 不预设研究目录。
- 后续 Agent 先读研究摘要，只在资料过期、互相冲突或缺少当前问题时补充搜索。
- 原始资料与摘要分开保存；默认向其他角色共享摘要和原始来源路径。
- 搜索结果返回主 Agent 时只保留会改变决策的事实、证据强弱和未知项。

## 返回主 Agent

sub-agent 不返回完整过程记录，默认返回：结论、关键依据、建议或完成内容、风险与未知项、需要主 Agent 决定的问题，以及重要文件路径。
