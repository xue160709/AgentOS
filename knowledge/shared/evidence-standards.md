# 证据标准

读取时机：本轮要产出、消费或审查外部事实与用户证据时。研究、策略、产品、验收和审查角色共用本文件。

"事实、外部证据、推论、假设、模拟观点"的定义见 [`glossary.md`](glossary.md)；本文件定义强度分级、引用格式、条目结构、冲突与过期处理。

## 强度分级

从强到弱：

1. 直接行为观察与系统可观测数据
2. 任务过程记录（用户完成任务时的实际步骤、耗时、失败点）
3. 原始访谈、工单与一手反馈
4. 多个独立来源或独立用户呈现的一致模式
5. 公开评论与社区讨论
6. 二手总结、分析文章与榜单
7. 专家推断与模型记忆
8. 模拟观点

分级表示"被推翻的难度"，不表示适用性：不同证据回答不同问题，不能只按层级高低或数量多少取舍。第 8 级不构成证据，只能用来提出待验证问题。

第 5 级及以下不能单独支撑"存在市场需求"、"用户愿意付费"、"我们领先"、"这是主要痛点"这类结论；需要这类结论时，说明还缺哪一级证据。

## 引用格式

每条外部事实附：来源链接或可定位位置、获取日期、口径（地区、时间范围、样本、单位、计算方式）、适用范围、已知反例。

缺少口径的数字按不可引用处理——写出"该数字缺少口径"，而不是先引用再补注。

## 条目结构

| 字段 | 要求 |
|---|---|
| 结论 | 一句话，可证伪 |
| 类型 | 事实 / 外部证据 / 推论 / 假设 / 模拟观点 |
| 强度 | 上表级别 |
| 依据 | 来源 + 获取日期 + 口径 |
| 适用范围 | 地区、人群、时间、产品形态 |
| 反例与冲突 | 并列呈现，不省略 |
| 仍需验证 | 具体的下一步验证方式，不写"待进一步研究" |

## 冲突与过期

- 来源冲突时并列呈现全部版本及各自口径，不静默选择更符合预期的一个；无法判断哪个成立时作为未决项交回主 Agent。
- 外部事实标记获取日期与**复核条件**——说明在什么情况下必须重新核对（例如"竞品定价，引用前复核"、"政策数据，季度更新"）。满足复核条件仍要引用时先复核。
- 新证据推翻旧结论时标明 superseded 并保留原记录，不覆盖。

## 常见误判

| 材料 | 能证明 | 不能证明 |
|---|---|---|
| 官方产品页与定价页 | 对方如何宣传、承诺了什么、如何划分套餐 | 实际效果、市场份额、用户满意度 |
| 搜索热度、评论数、社区讨论量 | 存在关注与话题 | 付费意愿、需求强度、问题优先级 |
| 用户访谈陈述 | 用户如何描述和解释自己 | 用户实际会怎么做 |
| 单一用户或少量轶事 | 该情境真实存在 | 分布、频率、代表性 |
| 融资额、榜单、增长报道 | 有人下注、存在关注 | 产品被使用、被留存、被付费 |
| 模型记忆与模拟角色 | 可以提出待验证的问题 | 任何真实用户或市场事实 |
