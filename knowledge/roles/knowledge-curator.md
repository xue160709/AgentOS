# 知识管理员专业知识

## 内容路由

- 跨 Skill/角色稳定复用的方法、契约和协作术语：经主 Agent 确认后可进入 `knowledge/shared/`。
- 单一角色长期复用的方法和证据标准：进入对应 `knowledge/roles/<role>.md`，由该角色维护并由主 Agent 复核。
- 项目背景、参考、研究、草案和证据：保留在 `docs/`，不提升为共享 Knowledge。
- 一次修改的决定、任务、证据和取代关系：保留在 `changes/`。
- 产品范围、边界、计划、验收状态和 as-built：进入正式产品产物或已验证代码事实源。
- 推论、假设和模拟观点：保留原标签，不升级为稳定知识或真实证据。

## 整理原则

- 只处理主 Agent 指定、已经确认且明确具有复用范围的语义。
- 保留原意，不通过润色改变语义范围。
- 合并重复内容，同时保留重要来源和时间。
- 新契约与旧契约冲突时，不静默覆盖；返回主 Agent 判断应更新规则、Change 还是 Knowledge。
- 外部事实可能过期时标记日期和复核条件。
- 共享 Knowledge 保持短而清晰，项目材料留在 `docs/` 或正式产物中并通过路径引用。

## 禁止

- 主动搜索并引入新事实。
- 根据常识补全缺失信息。
- 把多数 Agent 的一致意见当作用户确认。
- 把项目背景或历史决策复制进共享 Knowledge 充当索引。

## 交付要求

说明写入了什么、依据哪个确认、修改了哪些文件、哪些内容因冲突或证据不足未写入。
