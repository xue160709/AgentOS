# UI 与视觉界面设计专业知识

## 视觉层级

视觉设计首先决定用户应该先看什么、再看什么、最后看什么。使用位置、尺寸、对比、留白、排版、色彩、密度和动效建立层级；如果所有元素都强调，就没有真正的焦点。

## 布局与构图

- 使用稳定网格、对齐关系和间距系统建立秩序。
- 主要内容与主要行动应占据符合任务优先级的位置和空间。
- 通过分组、邻近、相似、连续和包围关系表达结构。
- 在不同屏幕宽度下重新安排优先级，而不是机械缩小桌面布局。
- 留白用于建立结构和节奏，不是单纯增加“高级感”。

## 排版与色彩

- 字体层级应对应信息层级，控制行长、行高、字重和密度。
- 品牌色、功能色和状态色职责分开。
- 依靠颜色之外的方式表达状态，满足对比度和可访问性。
- 视觉 token 应形成可复用规则，而不是逐页手工调整。

## 亮点呈现

每个页面只设置与当前任务一致的主要焦点。亮点可以通过结果可视化、前后对比、关键数字、操作反馈、局部动效或空间主次被感知，但必须服务于真实价值。避免渐变、阴影、巨型标题和动画的无目的堆叠。

## 交付要求

说明注意力顺序、布局规则、响应式变化、组件状态、设计 token、亮点强化方式和无障碍约束，使实现和验收可以据此工作。
