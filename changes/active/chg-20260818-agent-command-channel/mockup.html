0 · 四条状态条规矩（所有 mockup 共用）

规矩一未知不冒充结论：拿到真实状态前只显示「正在打开预览…」，绝不显示「未初始化」或「已停止」。（修 R-04/R-06）
规矩二每个红色状态 = 一句原因 + 一个能走通的按钮；没有出路的报错不允许出现。（修 R-01/R-02/R-12/R-13/F1）
规矩三文案只说真话：没有上一版就不说「保留上一版」；跑的是 start 就不说「开发服务」。（修 R-05/F2/F14）
规矩四用户的定局不可被推翻：点过「停止」后，迟到的成功/失败事件一律作废。（修 R-07/R-18）
