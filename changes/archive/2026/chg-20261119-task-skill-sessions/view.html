在编排 Skills 时选择会话方式

打开创建或编辑任务卡表单，选择「编排 Skills」。会话方式放在 Skill 选择区下方、TODO 模式上方。

查看编辑表单　→

为什么需要这个设置

一组串行步骤可以各自在干净的会话里工作，也可以接着前一步的对话继续。

两种执行方式

每个 Skill 独立会话 · 默认每轮、每步都打开新会话，步骤间不传摘要。

所有 Skill 共用会话同一次启动的步骤共享对话上下文。

改动位置

任务卡表单保存会话方式，后台调度按选定方式逐步提交 Skill。

已有任务卡

旧配置缺少会话方式时，默认采用独立会话。依赖前一步对话的任务可以在编辑表单中选用共用会话。
