# 任务卡的会话方式

在现有创建和编辑任务卡表单中，选择「编排 Skills」后，在 Skill 选择区下方、TODO 模式上方增加「会话方式」。选项为「每个 Skill 独立会话」（默认）和「所有 Skill 共用会话」。会话方式随任务卡保存。

独立模式下，后台按已选列表顺序执行，每个实际执行的步骤在新的项目会话中启动。即使同一个 Skill 被添加两次，或任务设置了多轮运行，每次执行也从新会话开始。仅传当前任务和步骤的指令，各步骤仍能读取同一项目的文件。共用模式按一次启动复用一条会话。

界面落点为 ProjectHomeSurface.tsx 的任务表单，执行落点为 task-home-plugin-manager.ts 的任务调度循环。沿用原有运行状态及停止机制。本轮界面原型只展示编辑表单。

验收应覆盖设置保存与回显、独立与共用的上下文、串行顺序及重复轮次。读取无此配置的旧卡时直接采用独立会话，无需先编辑保存。
