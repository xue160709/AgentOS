# 任务卡会话方式验收
| 场景 | Given | When | Then |
|---|---|---|---|
| AC-SESSION-001 | 新卡或缺少字段的旧卡 | 选择编排 Skills 或打开旧卡 | Skill 列表下方、TODO 模式上方显示会话方式，默认为独立 |
| AC-SESSION-002 | 两步任务配置两轮运行 | 在独立模式启动 | 收到前一步结果才提交下一步，产生四个独立会话，每个请求只带自身步骤指令 |
| AC-SESSION-003 | 任务显式保存为共用 | 重新加载并执行两轮 | 配置回显为共用，四步使用同一会话 |
| AC-SESSION-004 | 独立任务已进入第二步 | 停止当前任务 | 取消第二步的请求，后续步骤不启动 |
