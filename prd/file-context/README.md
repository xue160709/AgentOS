# 本地文件上下文

## 模块定位

本地文件上下文模块让用户在 AgentOS 内安全浏览、搜索、预览和引用项目文件，并把文件作为聊天附件或 Agent 上下文来源。

## 当前已实现

- 项目文件树会忽略 `.git`、`node_modules`、`dist`、`.next` 等大型生成目录。
- 支持 Markdown、JSON、普通文本和 PNG/JPG/GIF/WEBP 图片预览，并有大小限制。
- 所有预览、搜索和路径存在性检查都限制在项目根目录内。
- Composer 支持 `@` 文件搜索，返回项目内文件或目录候选。
- 聊天附件支持文本和图片，总数和大小受前后端校验。
- Agent 项目文档面板只读写项目根固定文件：`AGENTS.md`、`SOUL.md`、`GOAL.md`。
- 项目上下文面板支持 `Context/` 指令和条目引用/复制。

## 用户流程

```text
1. 用户打开项目文件树或在 Composer 输入 @
   ↓
2. 系统在项目根内读取、搜索或预览文件
   ↓
3. 用户把文件作为上下文、附件或预览对象使用
```

## 还没做什么

- 文件上下文 acceptance 已完成正式验收状态同步；文件树、搜索、预览、附件和模型图片能力限制已有验收证据。
- 后续可补全页面点击式 E2E，把文件预览、`@` 搜索、附件提交和不支持图片模型的 UI 提示串成可重复脚本。

## 关键决策

- 项目文件读取由主进程统一做路径校验，渲染层不直接访问任意文件。
- 搜索和预览做上限控制，避免大型项目拖垮 UI。

## 验收

- 验收契约与实现状态见 `acceptance.md`。

## 关联模块

- `chat-agent-runtime`：使用文件搜索、预览和附件。
- `agent-mode`：使用项目文档和 Context 面板。
- `desktop-shell-settings-release`：通过 preload 暴露文件相关桌面能力。
