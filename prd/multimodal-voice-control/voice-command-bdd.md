# AgentOS 常用语音命令与 BDD

> 参考文档：从真实用户会说的任务出发，用于产品走查、人工 smoke、后续自动化用例设计。
> 唯一正式验收状态仍以 `prd/multimodal-voice-control/acceptance.md` 为准。

## BDD 场景

### 1. 打开 macOS 设置
- GIVEN AgentOS 主窗口可用
- WHEN 用户说「打开 macOS 设置」
- THEN 系统解析为打开系统设置应用，并启动 macOS System Settings

### 2. 打开 Wi-Fi 设置
- GIVEN AgentOS 主窗口可用
- WHEN 用户说「打开 Wi-Fi 设置」
- THEN 系统打开 macOS System Settings 的 Wi-Fi 页面；若系统不支持深链，则降级打开系统设置首页并回显原因

### 3. 打开蓝牙设置
- GIVEN AgentOS 主窗口可用
- WHEN 用户说「打开蓝牙设置」
- THEN 系统打开 macOS System Settings 的蓝牙页面；若系统不支持深链，则降级打开系统设置首页并回显原因

### 4. 打开声音设置
- GIVEN AgentOS 主窗口可用
- WHEN 用户说「打开声音设置」
- THEN 系统打开 macOS System Settings 的声音页面；若系统不支持深链，则降级打开系统设置首页并回显原因

### 5. 打开显示器设置
- GIVEN AgentOS 主窗口可用
- WHEN 用户说「打开显示器设置」
- THEN 系统打开 macOS System Settings 的显示器页面；若系统不支持深链，则降级打开系统设置首页并回显原因

### 6. 用 Safari 打开百度
- GIVEN 本机已安装 Safari
- WHEN 用户说「用 Safari 打开百度」
- THEN 系统用 Safari 打开 `https://www.baidu.com/`，并在命令窗口回显「已用 Safari 打开百度」

### 7. 用 Safari 搜索 AgentOS
- GIVEN 本机已安装 Safari
- WHEN 用户说「用 Safari 搜索 AgentOS」
- THEN 系统用 Safari 打开百度搜索结果页，搜索关键词为 `AgentOS`

### 8. 打开百度
- GIVEN AgentOS 主窗口可用
- WHEN 用户说「打开百度」
- THEN 系统解析为打开网页，通过默认浏览器打开 `https://www.baidu.com/`

### 9. 打开 Safari
- GIVEN 本机已安装 Safari
- WHEN 用户说「打开 Safari」
- THEN 系统启动 Safari，并在命令窗口回显执行结果

### 10. 打开微信
- GIVEN 本机已安装微信
- WHEN 用户说「打开微信」
- THEN 系统启动微信；若未安装，则回显「未找到微信」

### 11. 打开访达
- GIVEN macOS 桌面环境可用
- WHEN 用户说「打开访达」
- THEN 系统启动 Finder，并将其置前

### 12. 打开终端
- GIVEN macOS 桌面环境可用
- WHEN 用户说「打开终端」
- THEN 系统启动 Terminal，并将其置前

### 13. 新建对话
- GIVEN 主窗口已打开某个项目，独立命令窗口可用
- WHEN 用户说「新建对话」
- THEN 系统创建一个新 thread，切换到该 thread，并在命令窗口回显执行结果

### 14. 回到项目首页
- GIVEN 当前不在项目首页
- WHEN 用户说「回到项目首页」
- THEN 系统切换到当前项目首页，并保留当前项目上下文

### 15. 打开文档页
- GIVEN 当前不在文档页
- WHEN 用户说「打开文档页」
- THEN 系统切换到文档页，并展示项目相关文档入口

### 16. 搜索项目文件
- GIVEN 主窗口任意页面可用
- WHEN 用户说「搜索项目文件」
- THEN 系统打开搜索弹窗，并切换到文件搜索范围

### 17. 搜索对话
- GIVEN 主窗口任意页面可用
- WHEN 用户说「搜索对话」
- THEN 系统打开搜索弹窗，并切换到对话搜索范围

### 18. 打开文件面板
- GIVEN 右侧文件面板未打开
- WHEN 用户说「打开文件面板」
- THEN 系统打开右侧文件面板，并展示当前项目文件树

### 19. 关闭文件面板
- GIVEN 右侧文件面板已打开
- WHEN 用户说「关闭文件面板」
- THEN 系统关闭右侧文件面板，主工作区恢复完整宽度

### 20. 输入「总结这个项目」
- GIVEN Composer 可编辑
- WHEN 用户说「输入总结这个项目」
- THEN 系统把「总结这个项目」填入 Composer，但不自动发送

### 21. 发送「继续」
- GIVEN 主窗口当前对话可用
- WHEN 用户说「发送继续」
- THEN 系统把「继续」作为消息内容提交到当前对话

### 22. 打开第二个项目
- GIVEN 工作区至少有两个项目
- WHEN 用户说「打开第二个项目」
- THEN 系统切换到第二个项目，并更新项目首页与会话列表

### 23. 打开上一个对话
- GIVEN 当前项目至少有多个对话，且存在可识别的上一个对话
- WHEN 用户说「打开上一个对话」
- THEN 系统切换到目标对话，并展示对应消息记录

### 24. 置顶当前对话
- GIVEN 当前对话未置顶
- WHEN 用户说「置顶当前对话」
- THEN 系统将当前对话标记为置顶，并在对话列表中体现状态变化

### 25. 置顶当前项目
- GIVEN 当前项目未置顶
- WHEN 用户说「置顶当前项目」
- THEN 系统将当前项目标记为置顶，并在项目列表中体现排序或置顶状态

### 26. 打开模型设置
- GIVEN 主窗口任意页面可用
- WHEN 用户说「打开模型设置」
- THEN 系统打开全局设置，并定位到模型配置页

### 27. 切换到 MiniMax-M3
- GIVEN 模型设置中存在可用的 MiniMax-M3
- WHEN 用户说「切换到 MiniMax-M3」
- THEN 系统将当前请求模型切换为 MiniMax-M3，并在命令窗口回显结果

### 28. 现在用的是哪个模型
- GIVEN 设置页或当前运行快照中可读取模型配置摘要
- WHEN 用户说「现在用的是哪个模型」
- THEN 系统回答当前 Provider、当前请求模型和 API Key 是否已设置，且不泄露 Key 明文

### 29. 打开 Agent 状态
- GIVEN 主窗口任意页面可用
- WHEN 用户说「打开 Agent 状态」
- THEN 系统打开 Agent 状态面板，并展示当前 Provider、MCP 与运行状态摘要

### 30. 刷新任务卡
- GIVEN 项目首页任务卡已加载
- WHEN 用户说「刷新任务卡」
- THEN 系统刷新任务卡内容，并保持项目首页可操作

### 31. 截屏
- GIVEN macOS 桌面环境可用
- WHEN 用户说「截屏」
- THEN 系统打开 macOS 截屏工具或执行预设截图动作，并在命令窗口回显截图动作已触发

### 32. 截图并复制到剪贴板
- GIVEN macOS 桌面环境可用
- WHEN 用户说「截图并复制到剪贴板」
- THEN 系统截取屏幕内容并写入剪贴板；若需要用户框选区域，则进入系统截图选择模式

### 33. 把音量调大
- GIVEN 系统音量可控制
- WHEN 用户说「把音量调大」
- THEN 系统提高输出音量，并回显调整后的音量状态或成功提示

### 34. 静音
- GIVEN 系统音量可控制
- WHEN 用户说「静音」
- THEN 系统将输出音量切换为静音，并回显「已静音」

### 35. 开启勿扰模式
- GIVEN macOS 支持专注模式控制
- WHEN 用户说「开启勿扰模式」
- THEN 系统打开勿扰或专注模式；若当前系统不允许自动切换，则回显需要用户手动授权或设置的原因

### 36. 关闭勿扰模式
- GIVEN macOS 支持专注模式控制
- WHEN 用户说「关闭勿扰模式」
- THEN 系统关闭勿扰或专注模式；若当前系统不允许自动切换，则回显需要用户手动授权或设置的原因

### 37. 打开下载文件夹
- GIVEN 当前用户存在下载文件夹
- WHEN 用户说「打开下载文件夹」
- THEN 系统在 Finder 中打开 `~/Downloads`，并将 Finder 置前

### 38. 打开桌面文件夹
- GIVEN 当前用户存在桌面文件夹
- WHEN 用户说「打开桌面文件夹」
- THEN 系统在 Finder 中打开 `~/Desktop`，并将 Finder 置前

### 39. 打开最近的截图
- GIVEN 当前用户最近保存过截图
- WHEN 用户说「打开最近的截图」
- THEN 系统定位最近的截图文件并打开；若未找到截图，则回显「没有找到最近的截图」

### 40. 打开活动监视器
- GIVEN 本机已安装 Activity Monitor
- WHEN 用户说「打开活动监视器」
- THEN 系统启动 Activity Monitor，并在命令窗口回显执行结果

### 41. 打开备忘录
- GIVEN 本机已安装 Notes
- WHEN 用户说「打开备忘录」
- THEN 系统启动 Notes，并将其置前

### 42. 打开日历
- GIVEN 本机已安装 Calendar
- WHEN 用户说「打开日历」
- THEN 系统启动 Calendar，并将其置前

### 43. 打开邮件
- GIVEN 本机已安装 Mail
- WHEN 用户说「打开邮件」
- THEN 系统启动 Mail，并将其置前

### 44. 关闭当前窗口
- GIVEN 当前存在前台窗口
- WHEN 用户说「关闭当前窗口」
- THEN 系统关闭前台窗口；若目标应用需要确认保存，则不强制关闭并提示用户处理保存弹窗

### 45. 最小化当前窗口
- GIVEN 当前存在前台窗口
- WHEN 用户说「最小化当前窗口」
- THEN 系统最小化前台窗口，并保持 AgentOS 命令窗口可用

### 46. 切换到上一个应用
- GIVEN 系统记录了上一个活跃应用
- WHEN 用户说「切换到上一个应用」
- THEN 系统切换回上一个活跃应用；若无法判断目标，则提示用户说出应用名称

### 47. 百度搜索 Electron 多窗口通信
- GIVEN 默认浏览器可用
- WHEN 用户说「百度搜索 Electron 多窗口通信」
- THEN 系统打开百度搜索结果页，搜索关键词为 `Electron 多窗口通信`

### 48. 打开当前项目的 TODO
- GIVEN 当前项目存在 `TODO.md`
- WHEN 用户说「打开当前项目的 TODO」
- THEN 系统打开当前项目的 `TODO.md`，并在主窗口或文件查看器中展示内容

### 49. 总结当前对话
- GIVEN 当前 thread 中存在可读取的消息历史
- WHEN 用户说「总结当前对话」
- THEN 系统读取当前 thread 上下文并生成摘要，摘要中包含当前目标、已完成事项和未决问题

### 50. 帮我解释当前报错
- GIVEN 当前窗口或最近运行日志中存在可读取的报错文本
- WHEN 用户说「帮我解释当前报错」
- THEN 系统提取报错摘要，解释可能原因，并给出下一步排查建议；若无法读取报错，则提示用户选择目标日志或窗口
