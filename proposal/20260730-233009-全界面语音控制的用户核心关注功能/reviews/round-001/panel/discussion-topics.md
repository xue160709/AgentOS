# Round 001 Discussion Topics

## 匿名共识

- 三份评审都认为“已接收/已转交”与“已完成”必须由真实后置条件区分。
- 三份评审都要求超时、取消、重试与迟到事件共享稳定请求身份，不能产生重复副作用。
- 高频视角额外要求运行中继续准备下一条指令；首次视角额外要求首屏能力边界；恢复视角额外要求跨重启幂等和 CANCELLED 的证据。

## 是否需要讨论回应

- 不需要。本轮没有会改变 MUST 结论或评分的立场冲突；“NEED-003 满足/部分满足”的差异来自恢复视角发现了更严格但有效的关闭重开时序缺口，应直接交由独立裁决按最低有效体验处理，不以多数意见消除。

## 交给独立裁决的问题

- Agent 终态和后置条件不足应合并为一个根因还是拆分为范围承诺与协议完整性。
- 运行中排队是 NEED-006 的必要闭环，还是后续效率增强。
- 跨重启幂等、取消证据、首次范围承诺和能力目录免手浏览分别应定为 P1、P2 或 P3。
